# GO7 Red & White Responsive Design Update

इस अपडेट में reference screenshot के अनुसार GO7 के लिए लाल-सफेद design लागू किया गया है।

## Design changes
- Desktop पर category panels 3 columns में।
- Mobile पर category panels हमेशा 2 columns में (बहुत छोटी स्क्रीन पर भी)।
- Header masthead और navigation लाल-सफेद theme में।
- Category headings red bars में और links साफ text-list के रूप में।
- हर post के लिए अलग row border हटाया गया; spacing और hover state रखी गई।
- Typography को एक consistent scale में रखा गया ताकि heading, body और feed links का आकार संतुलित रहे।
- Main content width अधिकतम 1070px; सभी sections centered।
- Latest Updates और related posts responsive grid में।

## Deploy
ZIP extract करें और repository के `public` folder को replace/merge करें। Worker या D1 database में बदलाव की जरूरत नहीं है। `worker/.wrangler/` को git में add न करें।
